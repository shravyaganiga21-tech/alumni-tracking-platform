# AlumniConnect AI

AI-Powered Alumni Networking & Career Platform

## About

AlumniConnect AI is a full-stack platform that connects
college students, alumni, recruiters and administrators.

The platform provides:

- Alumni networking
- Mentorship
- Job opportunities
- Referral opportunities
- Events
- Career guidance
- AI-powered recommendations

## Tech Stack

- Flutter
- Python
- Flask
- Supabase
- PostgreSQL
- Gemini/OpenAI API
- Git
- GitHub
